🥷 NinjaX

NinjaX is a fast-paced endless parkour game where a ninja runs across a procedurally generated city skyline while escaping a relentless shadow beast. Built from scratch using standard web technologies, the game requires no game engine, external assets, dependencies, or backend.

✨ Features
🥷 Endless procedurally generated rooftop gameplay
🐺 Relentless shadow-beast pursuit
🦘 Jump, double-jump, and slide mechanics
🎯 Responsive movement with coyote time
🪙 Coins and multiplier globes
🌆 Procedural city skyline with parallax effects
🌉 Neon slides and holographic rooftop connectors
🌗 Dynamic day/night visual transitions
🔊 Procedurally generated music and sound effects
📱 Keyboard and touch controls
🏆 Local high-score system
⏸️ Pause, restart, and exit controls
⚡ No external runtime dependencies
🛠️ Tech Stack
HTML5 — Frontend structure, game interface, HUD, and controls
CSS3 — Frontend styling, responsive layout, animations, and neon visual effects
Vanilla JavaScript — Game logic, physics, controls, collision detection, and state management
HTML5 Canvas 2D — Rendering the ninja, rooftops, obstacles, collectibles, and environment
Web Audio API — Procedurally generated background music and sound effects
LocalStorage — Saving and managing the player's local high score
Git & GitHub — Version control and project management
GitHub Pages — Hosting and deploying the playable game

🕹️ How to Play

The ninja runs automatically across the rooftops. Your goal is to travel as far as possible, collect coins and multiplier globes, avoid obstacles, and stay ahead of the shadow beast.

Action	Keyboard	Touch
🦘 Jump	Space / ↑ / W	Tap upper half
🔄 Double Jump	Jump again in air	Tap upper half again
🧎 Slide	↓ / S	Tap lower half
⏸️ Pause	P / Esc	Pause button
🔄 Restart	Restart menu	Restart button
🏆 Goal

Run as far as possible, collect coins, activate multipliers, avoid rooftop obstacles and gaps, and stay ahead of the pursuing beast while trying to beat your local high score.

Run. Jump. Slide. Stay ahead. 🥷💨
